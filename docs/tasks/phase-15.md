## 決定

- 投稿・固定ページの新規作成後は、新しく発行された ID の編集画面に移る。日本語だけのタイトルには `post-` または `page-` と UUID の先頭 8 桁を組み合わせた仮スラッグを付ける。手入力したスラッグは以後タイトルに追従させない。
- 投稿・固定ページの書きかけは、同じブラウザの同じアカウントから復元できる。保存領域を使えない場合は画面に知らせる。複数タブを開いた場合は別々の控えを持つ。
- 本文の公開・保存中も既存項目に追記できる。保存が成功しても、その送信後に入力した変更には未保存の表示が残る。古い下書きを復元したときは、その下書きを作成した時点を基準に競合を判定する。
- 競合判定は [Phase 13 の仕様](phase-13.md) に従う。サーバーが秒単位の更新時刻を書き込み前に照合するため、同じ秒の更新や同時に到着した書き込みを検出できない場合がある。
- サイト・組織・フォーム設定はそれぞれ独立して保存する。Ctrl/Cmd+S は操作中のフォームに作用する。カスタマイズでは表示中のタブが対象になる。
