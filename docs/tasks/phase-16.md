## リンクの保存

- 新規リンクは同じタブで開き、`nofollow` を自動付与しない。「新しいタブで開く」を選ぶと、公開 HTML に `target="_blank"` と `rel="noopener noreferrer"` が付く。
- `example.com/guide` は `https://example.com/guide` として保存する。サイト内のパス、ページ内のアンカー、メール、電話のリンクも設定できる。
- 保存済みリンクの URL を編集した場合、以前のタブ指定、`rel`、`title` を引き継ぐ。タブ指定はチェックボックスで変更できる。
