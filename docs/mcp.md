# ChatGPT・Claude から kansoCMS を使う

接続すると、チャットで「料金について書いた固定ページを探して」「春のお知らせを下書きにして」と頼めます。公開前の記事も読み取れるので、接続先には下書きを扱ってよいアカウントやワークスペースを選んでください。

## 1. サイトの接続先とキーを用意する

1. MCP 対応版の kansoCMS が稼働しているサイトのドメインを確認します。サイトが `https://cms.example.com` なら、接続先は **`https://cms.example.com/api/mcp`** です。クラウドから接続する場合は、そのサービスから到達できる HTTPS の URL を使います。
2. サイトの管理者でログインし、サイドバーの **API キー** を開きます。名前には「Claude 編集用」など、どこで使うかが分かる名前を付けます。
3. 下表から **スコープ** を選び、**発行 → キーをコピー** を押します。キーの値を確認できるのは発行直後の一度だけです。接続先の認証情報欄に保存してください。会話にキーを貼り付ける必要はありません。

| やりたいこと | 選ぶスコープ |
| --- | --- |
| 投稿・固定ページをタイトルで探す、本文を読む、投稿タイプを調べる | `read` |
| 上記に加え、新しい投稿・固定ページを下書きとして保存する | `write` |

このキーは通常の REST API でも同じスコープを持ちます。接続先ごとに発行すると、あとで一つずつ失効できます。

## 2. 利用するサービスに登録する

### Claude

1. **Customize → Connectors** からカスタムコネクタを追加します。組織で利用している場合は、コネクタを管理する人が設定します。
2. 名前に「kansoCMS」、MCP サーバー URL に手順 1 の接続先を入力します。
3. 認証で **No sign in** を選び、**Request headers** に次の 1 行を追加します。画面によっては **Advanced** の中にあります。

   | ヘッダー名 | 値 |
   | --- | --- |
   | `Authorization` | `Bearer <コピーしたCMSのキー>` |

   山括弧ごと実際のキーに置き換え、`Bearer` とキーの間に半角スペースを 1 個入れます。
4. コネクタを保存し、会話で利用できるようにします。[Claude のカスタムコネクタ設定](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

### ChatGPT

ChatGPT での接続方法は、利用するプラグインが固定の API キーを受け取れるかで決まります。組織で用意された対応プラグインがある場合は、その認証情報欄に CMS のキーを登録します。認証方式が OAuth に限定されている接続画面では、現在の kansoCMS を直接接続できません。[ChatGPT の接続手順](https://help.openai.com/en/articles/12584461-connecting-custom-mcp-servers-in-chatgpt)

プラグインを構成する人は、`mcp.json` の各サーバーエントリに次のように URL と認証方式を指定します。下記は `mcp.json` の例です。実際のキーは接続時に入力します。OpenAI の公開申請フォームは固定 API キー方式に対応していません。[OpenAI のプラグイン認証仕様](https://developers.openai.com/plugins/build/plugins#fixed-bearer-tokens-and-api-keys)

```json
{
  "mcpServers": {
    "kanso": {
      "type": "streamable-http",
      "url": "https://cms.example.com/api/mcp",
      "extensions": {
        "com.openai": { "auth": { "type": "api_key", "headerScheme": "bearer" } }
      }
    }
  }
}
```

## 3. 読み取りを試し、下書きを確認する

まず「**kansoCMS の固定ページを最大 3 件、タイトルと ID 付きで一覧にして**」と頼みます。0 件でも一覧を取得できれば接続は成功です。ページがあれば「その中の『料金』の本文を要約して」と続けられます。

`write` での最初の操作には、次の依頼を使えます。

> 「春の営業案内」という固定ページを、スラッグ `spring-hours`、本文「4 月から土曜日も営業します。」で下書きにして。作成したページの ID を教えて。

管理画面の **固定ページ** でタイトルと本文を確認します。投稿の下書きは **投稿** に表示されます。公開する場合は編集画面で公開を選んで保存します。**アクティビティ** には作成に使ったキー名が記録されます。

## 接続できないとき

| 症状 | 確認すること |
| --- | --- |
| URL をブラウザーで開くと `405` が出る | この URL は MCP クライアントの `POST` を受け付けます。接続確認には、上の一覧取得を使います。 |
| `401` が出る | 接続先サイトで発行した有効なキーか、`Authorization` の値に `Bearer ` が付いているかを確認します。 |
| 読めるが下書き作成ツールが見えない | 下書き作成には `write` が必要です。接続に使うキーを変更したら、クライアントでツール一覧を再取得します。 |
| 同じスラッグがあると言われる、または作成直後に通信が切れた | 管理画面で同じタイトルとスラッグの下書きを探します。作成済みかを確認してから次の操作を選びます。 |

接続を終了するときは **API キー → 対象のキー → 失効** を選びます。次のリクエストからアクセスが止まります。ツール名・引数・返り値は [AI エージェント向けの操作仕様](mcp-agents.md) にあります。
